## Reflection

When I changed my program from procedural code to a class, the code became more organised. Before, most of the code was inside `Main()`. Now, the `Payroll` class contains the payroll data and methods such as `CalculateNetPay()` and `ChangeTaxRate()`.

I also learned how private fields, properties, constructors, and methods work together. The class can validate the data and makes the code easier to test.

C# static typing means I need to specify data types such as `double` and `decimal`. At first, this was a little difficult, but it helped me find errors during compilation. I also learned that using the correct data type is important in C#.
