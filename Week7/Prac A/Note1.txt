1. No, the SortedSet did not need .Sort() or similar methods. It automatically keeps the elements in sorted order when they are added.
2. SortedSet uses a self-balancing binary search tree called a red-black tree. I found this from the C# documentation and by checking how SortedSet maintains its order.
3. The duplicate score was not added a second time. SortedSet only stores unique elements, so adding the same score again does not create a duplicate.
