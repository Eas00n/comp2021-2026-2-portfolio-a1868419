1. My Dijkstra algorithm starts from the Start node and gives it a distance of 0. All other nodes start with a very large distance. The algorithm uses a PriorityQueue to check the node with the smallest known distance. For each connected node, it calculates a new distance using the current distance and the edge weight. If the new distance is smaller, it updates the distance and stores the current node as the parent. When it reaches End, the parent nodes are used to build the shortest path.

2. The computational complexity of Dijkstra's algorithm with a PriorityQueue is O((V + E) log V). V means the number of nodes and E means the number of edges. BFS and DFS are usually O(V + E) because they only need to visit the nodes and edges. Dijkstra is different because it also needs to compare distances and use a PriorityQueue to select the next node with the smallest distance.
